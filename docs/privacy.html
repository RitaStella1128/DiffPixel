Privacy Policy

Effective date: May 27, 2025 / DiffPixel Chrome Extension

DiffPixel does not collect, transmit, sell, or share personal data. Reference images and settings stay on your device.

1. Overview

DiffPixel is a visual comparison extension for designers and developers. It lets you place local reference images over the current browser page and adjust layers, opacity, position, scale, blend modes, and a grid.

This policy explains what data the extension handles and how it is used.

2. Data We Do Not Collect

DiffPixel does not collect, store on external servers, transmit, sell, or share:

  • Personal information such as name, email address, or IP address.
  • Browsing history or page contents.
  • Uploaded or pasted reference images.
  • Keystrokes, clicks, or mouse activity.
  • Saved layer settings or visual comparison data.

3. Data Stored Locally

The extension may store reference images, layer names, position, opacity, scale, blend mode, grid settings, panel position, theme, and language preference in Chrome storage on your device.

This local storage is used only to restore your visual comparison setup and improve day-to-day usability.

4. Permissions

DiffPixel uses Chrome extension permissions only to run the overlay on the active tab, inject the in-page panel, and save local settings. Optional site access can be granted by the user so the panel can reopen on trusted domains.

5. Third Parties

DiffPixel does not use analytics, advertising networks, tracking scripts, or external APIs to process your data.

6. User Control

You can remove saved data by clearing the extension's stored settings in Chrome, removing layers in the panel, or uninstalling the extension.

7. Contact

For questions about this policy, please contact the repository owner through the public GitHub repository.

プライバシーポリシー

施行日: 2025年5月27日 / DiffPixel Chrome 拡張機能

DiffPixel は個人データを収集、送信、販売、共有しません。参照画像と設定はユーザーの端末内に保存されます。

1. 概要

DiffPixel は、デザイナーや開発者向けの視覚比較用 Chrome 拡張機能です。現在のブラウザページ上にローカルの参照画像を重ね、レイヤー、不透明度、位置、スケール、合成、グリッドを調整できます。

本ポリシーでは、拡張機能が扱うデータと、その利用目的を説明します。

2. 収集しないデータ

DiffPixel は、以下のデータを収集、外部サーバー保存、送信、販売、共有しません。

  • 氏名、メールアドレス、IPアドレスなどの個人情報。
  • 閲覧履歴やページ内容。
  • アップロードまたは貼り付けた参照画像。
  • キー入力、クリック、マウス操作の履歴。
  • 保存されたレイヤー設定や視覚比較データ。

3. 端末内に保存されるデータ

拡張機能は、参照画像、レイヤー名、位置、不透明度、スケール、合成モード、グリッド設定、パネル位置、テーマ、言語設定を Chrome ストレージに保存する場合があります。

これらは比較作業の状態を復元し、日常的に使いやすくするためだけに利用されます。

4. 権限

DiffPixel は、アクティブなタブでオーバーレイを動かし、ページ内パネルを挿入し、ローカル設定を保存するために Chrome 拡張機能の権限を使用します。ユーザーが許可した場合のみ、信頼したドメインでパネルを自動的に再表示するための任意のサイトアクセスを使用します。

5. 第三者サービス

DiffPixel は、分析、広告ネットワーク、トラッキングスクリプト、外部APIを使ってユーザーデータを処理しません。

6. ユーザーによる管理

保存データは、Chrome の拡張機能設定から保存内容を削除する、パネル内でレイヤーを削除する、または拡張機能をアンインストールすることで削除できます。

7. お問い合わせ

本ポリシーに関する質問は、公開 GitHub リポジトリの管理者までお問い合わせください。
