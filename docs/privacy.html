DiffPixel

Privacy Policy

Last updated: June 8, 2026 / DiffPixel Chrome Extension

DiffPixel does not collect, transmit, sell, or share personal data. Reference images and settings stay on your device.

1. Overview

DiffPixel is a visual comparison extension for designers and developers. It lets you place local reference images over the current browser page and adjust layers, opacity, position, scale, blend modes, and a grid.

2. Data We Do Not Collect

DiffPixel does not collect, store on external servers, transmit, sell, or share:

  • Personal information such as name, email address, or IP address.
  • Browsing history, page contents, form input, credentials, or keystrokes.
  • Uploaded or pasted reference images.
  • Saved layer settings or visual comparison data.

3. Data Stored Locally

The extension may store reference images, layer names, position, opacity, scale, blend mode, grid settings, panel position, theme, language preference, and site-level panel visibility in Chrome storage on your device.

This local storage is used only to restore your visual comparison setup and improve day-to-day usability.

4. Permissions

DiffPixel uses Chrome extension permissions to inject its local content script and CSS, display the in-page floating panel, overlay user-provided reference images, and save local settings.

Host access for HTTP, HTTPS, and local file pages is required because DiffPixel is designed to work on user-selected pages, and those pages cannot be known in advance. Local file pages also require the user to enable Chrome's file URL access setting for the extension. Host access is used to inject the local overlay and restore the panel after reloads on pages where the user has enabled DiffPixel.

5. Network Use and Remote Code

DiffPixel does not use analytics, advertising networks, tracking scripts, external APIs, remote fonts, or remote code. The extension's scripts and styles are packaged with the extension.

6. User Control

You can remove saved data by clearing the extension's stored settings in Chrome, removing layers in the panel, or uninstalling the extension.

7. Contact

For questions about this policy, please contact the repository owner through the public GitHub repository.

プライバシーポリシー

最終更新日: 2026年6月8日 / DiffPixel Chrome 拡張機能

DiffPixel は個人データを収集、送信、販売、共有しません。参照画像と設定はユーザーの端末内に保存されます。

1. 概要

DiffPixel は、デザイナーや開発者がブラウザ上で視覚比較を行うための拡張機能です。現在のページ上にローカルの参照画像を重ね、レイヤー、不透明度、位置、スケール、合成モード、グリッドを調整できます。

2. 収集しないデータ

DiffPixel は、以下のデータを収集、外部サーバー保存、送信、販売、共有しません。

  • 氏名、メールアドレス、IPアドレスなどの個人情報。
  • 閲覧履歴、ページ内容、フォーム入力、認証情報、キーストローク。
  • アップロードまたは貼り付けた参照画像。
  • 保存されたレイヤー設定や視覚比較データ。

3. 端末内に保存されるデータ

拡張機能は、参照画像、レイヤー名、位置、不透明度、スケール、合成モード、グリッド設定、パネル位置、テーマ、言語設定、サイト単位のパネル表示状態を Chrome ストレージに保存する場合があります。

これらの保存データは、視覚比較の状態を復元し、日常的に使いやすくするためだけに使用されます。

4. 権限

DiffPixel は、ローカルの content script と CSS をページに挿入し、ページ内フローティングパネルを表示し、ユーザーが追加した参照画像を重ね、ローカル設定を保存するために Chrome 拡張機能の権限を使用します。

DiffPixel はユーザーが選んだページ上で動作することを目的としており、対象ページを事前に固定できないため、HTTP、HTTPS、ローカルファイルページへのホストアクセスが必要です。ローカルファイルページでは、Chrome の拡張機能詳細でファイル URL アクセスをユーザーが有効にする必要があります。ホストアクセスはローカルのオーバーレイを挿入し、DiffPixel が有効なページでリロード後にパネルを復元するために使用します。

5. ネットワーク利用とリモートコード

DiffPixel は、分析、広告ネットワーク、トラッキングスクリプト、外部API、リモートフォント、リモートコードを使用しません。拡張機能のスクリプトとスタイルは拡張機能内に同梱されています。

6. ユーザーによる管理

保存データは、Chrome の拡張機能設定から保存内容を削除する、パネル内でレイヤーを削除する、または拡張機能をアンインストールすることで削除できます。

7. お問い合わせ

本ポリシーに関する質問は、公開 GitHub リポジトリの管理者までお問い合わせください。
