Privacy Policy

Last updated June 8, 2026 · Version 1.1.0

DiffPixel does not collect, transmit, sell, or share personal data. Reference images and settings stay on your device.

Overview Data we do not collect Storage Permissions Network Your control Contact

Overview

DiffPixel is a visual comparison extension for designers and developers. It places local reference images over the current browser page and provides controls for layers, opacity, position, scale, blend modes, and a grid.

Data we do not collect

DiffPixel does not collect, store on external servers, transmit, sell, or share:

  • Personal information such as name, email address, or IP address.
  • Browsing history, page contents, form input, credentials, or keystrokes.
  • Uploaded or pasted reference images.
  • Saved layer settings or visual comparison data.

Storage

The extension may store reference images, layer names, position, opacity, scale, blend mode, grid settings, panel position, theme, language preference, and site-level panel visibility in Chrome storage on your device.

This local storage is used only to restore your visual comparison setup and improve day-to-day usability.

Permissions

DiffPixel uses Chrome extension permissions to inject its packaged content script and CSS, display the in-page floating panel, overlay user-provided reference images, and save local settings.

Host access for HTTP, HTTPS, and local file pages is required because DiffPixel works on pages selected by the user, which cannot be known in advance. Local file pages also require the user to enable Chrome's file URL access setting. Host access is used to display the local overlay and restore the panel on pages where DiffPixel has been enabled.

Network

DiffPixel does not use analytics, advertising networks, tracking scripts, external APIs, remote fonts, or remote code. The extension's scripts, styles, and assets are packaged with the extension.

Your control

You can remove saved data by clearing the extension's stored settings in Chrome, removing layers in the panel, or uninstalling the extension.

Contact

For questions about this policy, contact the repository owner through the public GitHub repository.

プライバシーポリシー

プライバシーポリシー

最終更新日 2026年6月8日 · バージョン 1.1.0

DiffPixelは個人データを収集、送信、販売、共有しません。参照画像と設定はユーザーの端末内に留まります。

概要 収集しないデータ 保存 権限 通信 データの管理 連絡先

概要

DiffPixelは、デザイナーや開発者がブラウザ上で視覚比較を行うための拡張機能です。現在のページ上にローカルの参照画像を重ね、レイヤー、不透明度、位置、スケール、合成モード、グリッドを調整できます。

収集しないデータ

DiffPixelは、以下のデータを収集、外部サーバー保存、送信、販売、共有しません。

  • 氏名、メールアドレス、IPアドレスなどの個人情報。
  • 閲覧履歴、ページ内容、フォーム入力、認証情報、キーストローク。
  • アップロードまたは貼り付けた参照画像。
  • 保存されたレイヤー設定や視覚比較データ。

保存

拡張機能は、参照画像、レイヤー名、位置、不透明度、スケール、合成モード、グリッド設定、パネル位置、テーマ、言語設定、サイト単位のパネル表示状態を端末内のChromeストレージに保存する場合があります。

これらのデータは、視覚比較の状態を復元し、日常的に使いやすくするためだけに使用されます。

権限

DiffPixelは、同梱されたcontent scriptとCSSをページへ挿入し、フローティングパネルを表示し、ユーザーが追加した参照画像を重ね、ローカル設定を保存するためにChrome拡張機能の権限を使用します。

ユーザーが選んだページ上で動作し、対象を事前に固定できないため、HTTP、HTTPS、ローカルファイルページへのホストアクセスが必要です。ローカルファイルでは、Chromeの拡張機能詳細でファイルURLアクセスを有効にする必要があります。ホストアクセスはローカルオーバーレイの表示と、有効なページでのパネル復元に使用します。

通信

DiffPixelは、分析、広告ネットワーク、トラッキングスクリプト、外部API、リモートフォント、リモートコードを使用しません。拡張機能のスクリプト、スタイル、アセットは拡張機能内に同梱されています。

データの管理

保存データは、Chromeの拡張機能設定から保存内容を削除する、パネル内でレイヤーを削除する、または拡張機能をアンインストールすることで削除できます。

連絡先

本ポリシーに関する質問は、公開GitHubリポジトリの管理者までお問い合わせください。
