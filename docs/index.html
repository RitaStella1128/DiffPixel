ワークフロー / 01—03

3つの状態。
1つの明確な結果。

追加整列差分
01 / 追加

参照画像をページへ。

ファイル選択、ドロップ、貼り付け。画像は端末内に留まり、作業しているそのページに表示されます。

02 / 整列

1px単位で、合わせる。

X・Y、スケール、不透明度を調整。実装ページを見たまま、参照画像を正しい位置へ合わせます。

03 / 差分

差分だけを、浮かび上がらせる。

合成モードを切り替えると、一致部分は後退し、修正すべき箇所だけが明確に残ります。
